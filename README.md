## 🤖 Flujo del Chatbot IA

### **Paso 1: Solicitar Ubicación**
El agente pregunta de dónde llama el cliente e identifica la sucursal más cercana.

### **Paso 2: Ofrecer Registro**
Pregunta si desea registrarse para información más precisa.

### **Paso 3: Capturar Datos**
- Nombre completo
- Número celular
- Fecha de nacimiento
- Lugar de nacimiento

### **Paso 4: Responder Preguntas**
El agente puede:
- Recomendar productos según necesidades
- Explicar cómo hacer compras
- Dar información de sucursales
- Responder dudas generales

## 🚀 Cómo Usar

1. **Abre en Navegador**: Accede a `index.html` en tu navegador web
2. **Interactúa con el Chatbot**: Haz clic en el botón "💬 Chat IA"
3. **Indica tu Ubicación**: Dile de dónde llamas
4. **Regístrate**: Proporciona tus datos cuando se solicite
5. **Explora Productos**: Navega por el catálogo y filtra por categoría
6. **Haz Preguntas**: El agente IA está listo para ayudarte
